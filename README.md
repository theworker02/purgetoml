# purgetoml

Purge color toml values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/purgetoml/

## Install / run

```bash
git clone https://github.com/theworker02/purgetoml.git
cd purgetoml
node src/cli.js
node --test
```
